# 更新记录

## v1.0.3（2026-09-05）

**修复**
- 修复所有确认弹窗点击「确定」后仍被当作「取消」处理的问题（`ui.js#confirmModal` 的 Promise 结果被 `onClose` 覆盖）：文件删除、设备推送确认等操作从此立即生效。
- 修复收件箱按钮无事件绑定的问题：网页推送「接收并下载 / 拒绝」、OpenLAN 实例直传「接收 / 拒绝」此前点击无任何反应，现统一走 `#inboxList` 事件委托。
- 修复推送给多个目标**全部失败**时只返回笼统 `HTTP 400` 的问题，改为返回可读原因（如“对端设备已离线”）。
- 文件被占用导致删除失败时，给出明确提示（不再误报“文件不存在”）。

**增强**
- 「我的文件」新增**搜索过滤**、**全选**、**批量删除**；「刷新」与浏览器**切回前台**时自动同步共享目录最新内容。
- 删除操作统一带确认弹窗；批量删除逐个执行并汇总成功 / 失败明细。

**其它**
- 浏览器 E2E 迁移为常驻工具 `tools/e2e-browser.mjs`，并新增“删除确认”回归用例；README 与两份文档整体修订。

## v1.0.2（2026-08）

- 「发起传输」弹窗新增「从本机选择文件…」：手机 / 电脑上的文件可直接多选上传并随本次一起发送给目标设备。

## v1.0.1（2026-07）

- 修复手机无法访问的根因：根级静态资源（Logo 等）未路由导致 404、Windows 防火墙拦截。现 `/favicon.ico|svg` 等根资源直接映射 Logo；启动横幅增加防火墙放行提示。
- 共享 / 接收目录以相对路径展示（如 `.\shared`），`bootstrap` 增补 `sharedDirAbs` 字段。
- 主题升级为四档：粉色（默认）→ 跟随系统 → 白色 → 黑色，含防闪屏预置脚本与设置内分段选择。
- 移动端全面适配：≤700px / ≤460px 断点布局、16px 输入防 iOS 缩放、横滑标签、弹层近全宽。

## v1.0.0（2026-06）

- 首个正式版本：局域网浏览器即用、多线程 Range 分片下载、网页会话推送、OpenLAN 实例点对点直传（含无人值守）、二维码 / 提取码分享、文本闪电传、传输坞、PIN 门禁、双向 SHA-256 校验、多主题与移动端适配。
