# OpenLAN 使用文档

OpenLAN 是一款运行在**局域网**内的开源文件急速传输工具：无需注册、无需外网，浏览器即用。它提供三种主要传输方式，并内置分片并发下载、设备点对点直传、二维码/提取码分享等能力。

> **作者：科技酱** · 开源协议：MIT

> 默认端口 **5555**。所有传输流量只在本机局域网内流动，不经任何第三方服务器。
> 当前版本：**v1.0.3**

---

## 1. 功能一览

| 能力 | 说明 |
| --- | --- |
| 访问下载传输 | 任意浏览器打开本机地址，即可浏览、上传、下载共享目录文件；下载走 **HTTP Range 多线程分片**，实测比单线程快数倍 |
| 设备选择传输 | 把文件/文本**推送给指定设备**：网页会话需对方点击确认；OpenLAN 实例可点对点直推存盘（支持无人值守自动接收） |
| 二维码扫描传输 | 手机相机/微信扫码直达本机页面；把任意文件生成**二维码或提取码**，扫码 / 输码即领 |
| 文本闪电传 | 不建文件，纯文本瞬时直达，收方可一键复制或保存为 `.txt` |
| 传输坞 | 底部实时进度条，聚合所有下载/推送/接收任务 |
| 多彩主题 / 移动适配 | 顶部「主题」一键循环：粉色(默认) → 跟随系统 → 白色 → 黑色；手机 / 平板自动响应式布局与触控优化 |
| 安全 | 可选 PIN 门禁、文件令牌下载链接、双向 SHA-256 完整性校验 |

## 2. 安装与启动

环境要求：**Node.js 18+**（Windows / macOS / Linux）。

```bash
# 方式一：npm 安装依赖后启动
npm install
node server/index.js

# 方式二：启动脚本（Windows 双击）
bin/start.bat

# 方式三：macOS / Linux
bash bin/start.sh

# 方式四：CLI 入口
node bin/openlan.js --help
```

启动成功后，程序会**自动用默认浏览器打开本机页面**（不需要可加 `--no-open`）。终端同时打印**局域网访问地址**（含二维码）：

```
http://192.168.1.20:5555   ← 手机扫此二维码即可打开
  共享目录 : .\shared      ← 相对路径展示，随程序目录整体移动即可
  接收目录 : .\downloads
```

本机浏览器访问 `http://localhost:5555` 或 `http://127.0.0.1:5555` 亦可；但手机/其它设备必须使用**局域网 IP 地址**。终端与页面中的共享/接收目录按**相对路径**展示（如 `.\shared`），方便整体打包、移动目录后继续使用。

> **Windows 防火墙**：首次启动 Node.js 监听 `0.0.0.0` 时，系统可能弹出防火墙提示，请务必选择「允许 Node.js 访问专用网络（和公用网络）」。若已误点拒绝，请前往「Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙」手动放行 Node.js。

### 常用启动选项

```bash
# 指定共享目录 / 接收目录 / 端口
node server/index.js --dir "D:\我的共享" --download-dir "D:\接收" --port 8000

# 设置访问 PIN（防蹭网）
node server/index.js --pin 1234

# 无人值守：自动接收其它设备的文件推送
node server/index.js --auto-accept
```

> 命令行参数也可用环境变量代替，见「附录：参数与环境变量」。

## 4. 三种传输方式

### 4.1 访问下载传输（我的文件）

**上传**：点击大虚线上传区（或拖拽文件/文件夹到该区域）→ 文件进入共享目录，自动生成下载令牌。

**下载**：点文件行「下载」按钮，或勾选多个文件后点「下载」。浏览器会发起**多线程分片下载**（默认 6 个分片并发），所有分片校验合并后保存到系统下载目录。

**文件管理（含搜索与批量操作）**：
- 顶部「搜索」框可按文件名**即时过滤**；「刷新」按钮、或浏览器**切回前台时**都会自动同步共享目录最新内容；
- 勾选多文件后可一键 **发送 / 下载 / 分享 / 删除**；「全选」可一次选中当前列表中的全部文件；
- 单文件删除可点行内垃圾桶，多文件删除可先勾选再点「删除」；删除前都会弹出确认，文件正被占用时会给出可读的失败提示。

**链接分享**：点文件行「链接」图标复制直链，格式：

```
http://<主机>:5555/api/down/<24位文件令牌>
```

任何人拿到链接即可在局域网内下载（无需登录；令牌由实例密钥签名，改动文件名/大小即失效）。

### 4.2 设备选择传输

「设备」页会展示两类目标：

- **网页会话（浏览器设备）**：当前正打开你页面、与你同属一个实例的其它浏览器。给它发内容会生成一张 **offer 卡片**，对方在收件箱点「接收并下载」才真正下载。
- **OpenLAN 实例**：网络中发现（UDP 组播）或手动添加的其它 OpenLAN 设备。点「发送文件」后走**点对点直传**——数据从一个实例直接推送到另一个实例并写入对方接收目录，不经本页中转。

**操作步骤**：
1. 进入「设备」页，选择目标设备；
2. 点「发起传输」或设备行「发送文件」：在弹窗中——
   - **从本机选择文件…**：直接选取手机 / 电脑上的任意文件（支持多选），文件会自动上传入共享目录并随本次一起发送；
   - **从「我的文件」勾选…**：选择共享目录中已上传的文件；
   - 还可附一段文本随文件一起推送；
3. 网页会话端在其「收件箱」点**接收**；OpenLAN 实例默认在**收件箱**待你点接收，若对方以 `--auto-accept` 启动则自动落盘；
4. 传输坞实时显示进度与速度。

**文本闪电传**：设备行「文本」按钮，输入纯文本即可瞬时推送，收方可在卡片上一键复制或保存。

**手动添加设备**：组播被 AP 隔离/禁用的网络（如访客 Wi-Fi）无法自动发现时，在「设备」页底部「手动添加设备」输入对方 IP 与端口（如 `192.168.1.20:5555`）。对方的 PIN 若与本机不同，请在两台设备上使用相同的 `--pin` 才能互通。

### 4.3 二维码 / 提取码传输

**扫码连接本机**：顶部「二维码」会列出本机所有局域网 IP（如 Wi-Fi 与以太网同时在线），默认选中第一个非虚拟网卡地址。手机相机/微信扫一扫即可打开本机页面（同一局域网内）；若当前默认地址无法打开，可在弹窗里切换其它地址后重新扫码。若二维码链接带 `?share=XXXX`，扫码会自动进入领取流程。

**文件分享**：文件行「分享」按钮或「分享」菜单 → 勾选文件、设置有效期 → 生成：
- 二维码（扫码打开后自动领取下载）
- 提取码（8 位短码，如 `7K4Q2B1X`）
- 直链（`http://主机:5555/s/XXXX`，访问后跳转到领取页）

**领取**：任意页点「领取」→ 输入提取码 → 文件自动多线程下载到浏览器。

> 提取码保存在内存中，重启服务后失效；有效期最长 7 天（默认 24 小时）。

## 5. 设置

| 设置项 | 说明 |
| --- | --- |
| 下载并发线程数 | 向主机同时拉取的分片数，1~24，建议 4~12 |
| 分片大小 | 单个分片体积（0.5~16 MB），大文件推荐 4~8 MB |
| 自动接收网页推送 | 开启后收到网页推送自动确认并下载 |
| 主题外观 | 粉色(默认) / 跟随系统 / 白色 / 黑色；「跟随系统」随操作系统深浅色自动切换 |
| 本页设备名称 | 其它设备列表里看到的本机名字 |

浏览器会自动保存并复用本机设备指纹（sid），刷新页面后不会变。

## 6. 安全与隐私

- **PIN 门禁**：`--pin 1234` 启动后，所有页面与推送接口都需要 PIN（`/api/events`、`/api/qr` 等公开端除外；实例间 P2P 请求需在 HTTP 头携带相同的 PIN，否则拒绝）。
- **文件令牌**：下载/分享链接带 HMAC 签名的令牌，无法枚举遍历目录。
- **完整性校验**：上传与 P2P 分块传输均做 SHA-256 校验；浏览器下载端在非 HTTPS 局域网环境下使用内置纯 JS SHA-256，结果一致。
- **数据不落第三方**：接收目录默认 `<项目>/downloads`，由服务端写入；所有记录仅存内存，重启即清。

## 7. 常见问题

**Q：手机扫码打不开 / 提示无法访问？**

1. 确认手机与本机在同一局域网（同一路由器或电脑热点）。
2. 必须使用终端输出的「局域网访问」地址（如 `http://192.168.1.20:5555`），`localhost`/`127.0.0.1` 只能在电脑上访问。
3. 检查 Windows 防火墙是否放行 Node.js / TCP `5555`；可临时关闭防火墙测试。
4. 部分 Android 相机扫码会尝试用内置浏览器打开，若无反应，请用浏览器「扫一扫」或手动输入地址。
5. 公司/校园网络若开启 AP 隔离/访客隔离，设备间无法互访，请换到同一私有 Wi-Fi 或电脑热点。

**Q：手机 / 平板界面太小、不好操作？**
页面已针对手机与平板做响应式适配：窄屏自动隐藏次要信息、按钮图标化、弹层全宽、输入框放大到 16px（防 iOS 聚焦缩放）、设备卡片两列展示等。把顶部「二维码」的地址分享给手机即可体验。

**Q：怎么换主题？**
顶部「主题」按钮循环切换：粉色(默认) → 跟随系统 → 白色 → 黑色。或进入「设置」在「主题外观」里直接选择；选择会自动保存在当前浏览器。

**Q：共享目录显示的 `.\shared` 是什么？**
它是相对路径，表示「程序所在目录下的 shared 文件夹」。整包拷贝 / 换机器解压后目录结构不变，文件依然可访问；自定义的绝对路径目录（如 `D:\共享`）会原样显示。

**Q：设备互相发现不了？**
① 确认在同一网段；② 组播被禁时点「手动添加设备」；③ 检查防火墙是否放行 5555 端口与 UDP 46233 组播。

**Q：下载速度没有跑满带宽？**
到「设置」调高「并发线程数」（建议 4~12）与「分片大小」。OpenLAN 服务端原生支持 `Range`，可配合 IDM/迅雷等工具。

**Q：两台实例无法 P2P 直传？**
两台都要运行 OpenLAN 且可互访 HTTP 端口；两边 `--pin` 需一致（或都为空）。Windows 防火墙请放行 Node.js 专用网络。

**Q：收件箱的「网页推送」和「实例直传」有何区别？**
网页推送是*另一台浏览器*通过本机接口中转的会话推送，需要对方在本页确认；实例直传是两个 OpenLAN 服务端之间的数据面直连，文件直接落在接收目录，浏览器仅作遥控台。

## 附录：参数与环境变量

```text
--port <n>             HTTP 端口（默认 5555）
--bind <ip>            监听地址（默认 0.0.0.0）
--name <名称>           本机设备显示名称
--dir <路径>            共享目录（默认 ./shared）
--download-dir <路径>   接收目录（默认 ./downloads）
--data-dir <路径>       实例身份数据目录（默认 ~/.openlan）
--pin <PIN>             访问 / 推送 PIN 门禁
--auto-accept           无人值守自动接收
--no-discovery          关闭 UDP 组播发现
--p2p-threads <n>       实例直传分块并发数（默认 4，上限 32）
--p2p-chunk-kb <n>      实例直传分块大小 KB（默认 1024）
--wait-accept <秒>      等待对方接受时长（默认 180）
--quiet                 静默模式
--open                  启动后自动打开浏览器（默认开启）
--no-open               关闭启动后自动打开浏览器（测试/服务器环境用）
--version / --help
```

同名环境变量写法：`OPENLAN_PORT=8000 OPENLAN_PIN=1234 node server/index.js`（布尔开关为 `0/false/off` 时关闭）。
